## 📖 專案內容

---

## 🎯 這次要掌握的 5 個核心操作
1. **`git init`**：把資料夾變成 Git 倉庫（開始版本追蹤）
2. **`git add .`**：將改動放進準備區（暫存區）
3. **`git commit -m "..."`**：拍下快照存檔（遊戲存檔點）
4. **`git branch -M main`**：設定主分支名稱為 `main`
5. **`git push`**：上傳到 GitHub 雲端倉庫
