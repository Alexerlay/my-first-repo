🧠 Git 核心概念速查（Vibe Coding 必備）

1. 📸 Commit（存檔）

像遊戲存檔點。git commit -m "說明" 可以把目前的好狀態固定下來，改壞隨時能回退。

2. ☁️ Push（上傳）

把本機存檔同步到 GitHub 雲端倉庫，電腦換台或重灌也不怕程式遺失。

3. 🌿 Branch（分支）

開闢一個「平行時空」。讓 AI 在新分支上嘗試大改動，安全不影響主線。
